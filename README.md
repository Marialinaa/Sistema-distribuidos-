# 🌐 Sistemas Distribuídos

Repositório dedicado ao armazenamento de códigos-fonte, implementações práticas, exercícios e anotações teóricas desenvolvidas durante a disciplina de **Sistemas Distribuídos**.

---

## 📚 Tópicos de Estudo

* **Fundamentos:** Conceitos primordiais, tipologias e desafios no projeto de sistemas distribuídos.
* **Arquiteturas:** Middlewares, modelos Cliente-Servidor, redes Peer-to-Peer (DHT) e arquiteturas multicamadas.
* **Programação Distribuída:** Comunicação via API de Sockets, Chamada de Procedimento Remoto (RPC), sistemas baseados na Web e representação externa de dados.
* **Nomeação:** Nomes, identificadores, endereços, DNS e nomeação por atributos.
* **Sincronização:** Relógios lógicos, algoritmos de exclusão mútua e algoritmos de eleição.
* **Replicação e Consistência:** Gerenciamento de réplicas e modelos de consistência de dados.
* **Tolerância a Falhas:** Modelos e mascaramento de falhas, acordo em sistemas distribuídos, protocolos de COMMIT (2PC e 3PC) e métodos de recuperação.
